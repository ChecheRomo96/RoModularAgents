# Coordinate RoModular development

Use this skill for cross-repository implementation, ongoing delivery
coordination, or when establishing the development model for a RoModular
workspace.

Read these canonical files when available:

1. `../../../RoModularAgents/CONTRACT.md`
2. The adapter under `../../../RoModularAgents/repositories/` for every
   repository the user places in scope.
3. `../../../RoModularAgents/roles/ecosystem-coordinator.md`
4. `../../../RoModularAgents/roles/repository-developer.md`
5. `../../../RoModularAgents/workflows/coordinated-development.md`

Start by preparing a delivery brief. Create only the developer assignments
needed by the request, keep every assignment repository-scoped, and use the
workflow handoff format. Consolidate verified handoffs for the user. Do not
turn coordination into permission for unrequested edits, commits, publication,
or work in neighboring repositories.
