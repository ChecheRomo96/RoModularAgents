# Maintain a RoModular repository

Read these canonical files when available:

1. `../../../RoModularAgents/CONTRACT.md`
2. The matching file under `../../../RoModularAgents/repositories/`
3. `../../../RoModularAgents/roles/repository-maintainer.md`

Inspect the branch, worktree, recent history, and supported scripts before
editing. Keep changes inside the user's scope, preserve unrelated work, and use
the repository's checked-in entry points. Update API documentation, examples,
tests, package metadata, or changelog only when the implementation affects
them. Validate proportionally and state unavailable platform or hardware
checks.

Implementation authority does not imply permission to commit, push, merge,
tag, publish, or release.
